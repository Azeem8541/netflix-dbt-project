# MovieLens 20M Dataset Link

The dataset used for this project is the **MovieLens 20M Dataset** provided by GroupLens Research. Since the dataset size is too large to host directly on GitHub (~20 million ratings), you can download the raw zip file from the official link below:

* **Official Dataset Link:** [GroupLens MovieLens 20M Dataset](https://grouplens.org/datasets/movielens/20m/)
* **Direct Download (Zip):** [ml-20m.zip](https://files.grouplens.org/datasets/movielens/ml-20m.zip)

### Dataset Overview:
* **Ratings:** 20,000,263 ratings
* **Tags:** 465,564 tags
* **Movies:** 27,278 movies
* **Users:** 138,493 users
